# 経緯（Context）

Kiro プロバイダのコマンド補完（`/` および `$`）には、kiro-cli が
`_kiro.dev/commands/available` で公開する組み込みスラッシュコマンド（`/voice`、
`/feedback` など）が列挙される。これらの中には、ユーザーの環境によっては
動作しないものがある。表示を抑制したいという要望が生じた。

Kirodian には既に、プロバイダごとの「Hidden commands」設定
（`hiddenProviderCommands`、設定画面の "Hidden Kiro commands"）があり、
コマンド名を1行ずつ入力すると補完ドロップダウンから除外できる。補完は
incremental search（入力に対する絞り込み）も効く。

ここで「環境依存で動かないコマンドをデフォルトで非表示にする既定リストを
Kiro に持たせるか」を判断する必要が生じた。

# 要件（Requirements）

- 環境によって動かない組み込みコマンドを補完から抑制できること。
- どのコマンドが「動かない」かはユーザーの環境に依存するため、特定の
  コマンド集合を前提にしないこと。
- 既存機能で満たせるなら新規実装を増やさないこと。

# 決定（Decision）

- Kiro 向けのデフォルト非表示コマンドリストは実装しない。
- 既存の per-provider「Hidden commands」設定による手動抑制に委ねる。

# 結果（Consequences）

## メリット

- 新規コードを増やさない（YAGNI）。既存機能で要件を満たす。
- 「動かないコマンド」は環境依存であり、既定リストを持つと環境ごとに
  正しくないリストを押し付けることになる。手動設定なら各環境で正確に
  抑制できる。
- incremental search が効くため、抑制しなくても目的のコマンドへは
  すぐ到達でき、既定非表示の必要性が低い。

## デメリット

- 初見のユーザーは「Hidden commands 設定で手動抑制できる」ことに
  気づきにくい可能性がある（設定画面の説明文で補う）。
