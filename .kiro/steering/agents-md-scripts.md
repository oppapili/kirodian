# scripts 編集時に読む AGENTS.md

`scripts/` 配下を編集している。実装の前に、次を**必ず読む**:

1. ルート `AGENTS.md`。
2. `scripts/AGENTS.md`。

さらにルート `AGENTS.md` の「Loading and verification」より、ビルド・依存・
ロックファイル・ロケール/静的アセット import・`esbuild.config.mjs` の変更は
`scripts/AGENTS.md` の対象である。規約の正本は `AGENTS.md`（内容は転記しない）。
